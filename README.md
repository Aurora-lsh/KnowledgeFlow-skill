# KnowledgeFlow 学习整理

配合已连接的 **Notion 插件**，把上传的 PPT、PDF、Word 等学习资料整理为可持续完善的学习文档。

## 使用

1. 选择 **KnowledgeFlow 学习整理** 技能，或输入 `$knowledgeflow`。
2. 选择 **Notion 插件**，上传或指定学习资料。
3. 发送：**开始整理**。

未确定保存位置时，助手会询问目标 Notion 页面或数据库链接。随后自动整理、保存确定性更新；概念匹配不明确或来源冲突时，请用户审核。

## 能力

- 按知识点融合讲义、教材、习题、论文和笔记，保留各自来源。
- 根据学习反馈调整讲解深度，包含解释、例子、必要前置知识与自测题。
- 保留文件名、真实页码/幻灯片编号/章节段落等定位，不编造来源。
- 写入前检查已有文档，跳过重复内容；保留个人笔记与人工修改。
- 使用当前 Notion 插件完成保存，无需为此技能另建 API 服务或本地数据库。

文档解析能力取决于运行环境；扫描件、复杂图表、公式和旧格式无法可靠读取时会明确说明。技能提供工作流指引，不保证原子更新或绝对不重复。

## 文件

```text
SKILL.md             学习整理流程与触发规则
agents/openai.yaml   技能展示信息、Notion 依赖及调用设置
```

本地安装时，将本仓库内容放在技能目录中的 `knowledgeflow` 文件夹内。使用前需要连接并授权 Notion 插件访问目标位置。
