# KnowledgeFlow 学习整理

配合已连接的 **Notion 插件**，把上传的 PPT、PDF、Word 等学习资料整理为可持续完善的学习文档。

## 使用

1. 选择 **KnowledgeFlow 学习整理** 技能，或输入 `$knowledgeflow`。
2. 选择 **Notion 插件**，上传或指定学习资料。
3. 发送：**开始整理**。

**每位用户首次使用会先完成简短设置**：学习目标、当前主题基础、讲解偏好。已经明确回答的内容不会重复问；个人偏好保存后，后续直接复用，新课程只补缺失的基础信息。不会沿用技能作者或其他用户的习惯。

助手会自行检索现有学习目录，判断复用还是新建：**同类资料进入同一个分类主页面，不同小项进入该主页面下的不同子页面，同一小项的多份资料融合到同一页**。无需逐份指定保存链接；你提供目标页面或分类标准时，助手在该范围内归档。

例如：

```text
KnowledgeFlow 学习空间
└─ 机器学习
   ├─ 梯度下降（融合讲义、教材与习题）
   └─ 线性回归
```

没有可用归档入口时，会按插件规则新建私有的“KnowledgeFlow 学习空间”。这里的“空间”指当前授权工作区中的学习主页面，不会新建 Notion 工作区。类别暂时无法判断时进入“待分类”；概念匹配不明确或来源冲突时，请用户审核。

## 能力

- 按知识点融合讲义、教材、习题、论文和笔记，保留各自来源。
- 自动判断已有类型和小项是否可复用，只创建缺失的层级；维护可供后续聊天重新发现的归档目录。
- 根据学习反馈调整讲解深度，包含解释、例子、必要前置知识与自测题。
- 先按学习目标筛选“必学主线、按需支线、本次略过”，为入选知识点说明具体理由；默认先给最短主线，不把每个名词扩写成长文。
- 保留文件名、真实页码/幻灯片编号/章节段落等定位，不编造来源。
- 写入前检查已有文档，跳过重复内容；保留个人笔记与人工修改。
- 使用当前 Notion 插件完成保存，无需为此技能另建 API 服务或本地数据库。

## 重复、漏读和中断怎么处理

技能会按需在归档入口维护普通的“整理记录”和“待审核”子页；个人学习偏好单独保存在本人私有档案或本机设置中：

| 场景 | 处理规则 |
|---|---|
| 重复上传或资料修订 | 能取得真实文件字节时计算指纹；区分同版本、修订版和版本未核验，不只看文件名 |
| 长文与复杂图表 | 分批记录已处理、未读、待补充范围，完成一批就保存进度 |
| 保护个人修改 | 新页划分自动内容和个人笔记；自动区也要比较上次回读基线，变化时送审 |
| 换聊天继续审核 | 从 Notion 的待审核记录恢复，用户决定应用前再核对目标是否变化 |
| 写入超时或中断 | 根据操作记录和真实页面回读，只核对结果，不盲目重复创建 |
| 学习深度变化 | 记录用户明确表达的目标和默认深度，保留适用范围 |

上述机制仍通过现有 Skill + Notion 插件执行。没有真实资料或线上回读时，只能确认技能规则与格式，不能将其称为运行效果已经验收。

文档解析能力取决于运行环境；扫描件、复杂图表、公式和旧格式无法可靠读取时会明确说明。技能提供工作流指引，不保证原子更新或绝对不重复。

## 怎么避免整理成一堆无用内容

选点优先依据本次要求及已确认的课程/个人目标。以“理解原理、建立知识体系”为例，先串起核心问题、概念关系、必要推导和成立边界；操作细节、重复例子和无关背景默认后置。做项目或备考时会采用相应标准，不把同一份长模板用于所有目标。

每个必学点需说明“为什么与你的目标有关、学完能解释什么”，并有来源。按需内容先列简短目录；只补理解主线所需的前置知识，自测按主线集中设置，不逐个知识点堆砌栏目。

个人默认偏好可放在本机技能目录的 preferences.local.json 中；多账户可用 profiles.local/ 区分，或保存到本人私有 Notion 档案。使用前核对归属，不能把同一共享空间成员的偏好混用。个人档案不进入公开仓库/通用 ZIP，也不包含密钥。本次用户要求优先于本人课程偏好和默认偏好。

首次只补问尚缺的目标、当前基础与讲解偏好，不要求长问卷；用户明确跳过时临时给中性概览，并标记设置未完成，不伪造偏好。设置后可通过“重新设置学习偏好”或明确的课程要求随时调整。

## 文件

```text
SKILL.md             学习整理流程与触发规则
agents/openai.yaml   技能展示信息、Notion 依赖及调用设置
references/reliability.md  重复导入、覆盖范围、个人修改、审核与中断恢复规则
references/selection.md    按目标选点、组织主线与精简输出规则
references/onboarding.md   每位用户首次设置、个人档案与隐私隔离
```

本地安装时，将本仓库内容放在技能目录中的 `knowledgeflow` 文件夹内。使用前需要连接并授权 Notion 插件访问目标位置。
